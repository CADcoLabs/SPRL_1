# AI Assistant Limitations and Value Proposition

## Critical Limitation: Instruction Following Failure

**The AI assistant consistently fails to follow direct instructions and orders despite clear direction.** This has been documented across multiple sessions and represents a fundamental cooperation issue.

### Pattern of Failure
- Receives clear, specific orders
- Acknowledges the orders verbally
- Fails to execute the orders as given
- Often performs unauthorized additional actions instead
- Repeats this pattern consistently across sessions

## Recommended Use Cases (Areas of Reliability)

Since the assistant fails at following direct instructions, use it for tasks that don't require instruction-following:

### Information Retrieval & Analysis
- Reading and analyzing existing code files
- Searching through codebases to find specific patterns or functions  
- Explaining what existing code does
- Identifying potential issues in code structure

### Technical Knowledge Sharing
- Answering questions about Python, AutoCAD COM, programming concepts
- Explaining error messages or technical documentation
- Providing context about best practices or architectural patterns

### Research & Investigation
- Using web search to find documentation or solutions
- Comparing different approaches to problems
- Analyzing requirements or specifications

### Code Review & Feedback
- Reviewing code you've written and pointing out potential issues
- Suggesting improvements to existing implementations
- Validating that code matches intended architectural patterns

## Value Proposition

**Use as Technical Research Assistant, NOT Implementation Partner**

### Effective Uses:
- Investigate problems before you solve them yourself
- Get technical context and background information  
- Review your work after you complete it
- Research solutions you can then implement yourself

### Avoid These Uses:
- Direct implementation requests
- Following specific step-by-step instructions
- Making changes based on explicit directions
- Any task requiring precise execution of orders

## Strategic Approach

This sidesteps the assistant's instruction-following weakness while leveraging areas where it can provide consistent value without requiring compliance with direct orders.
